## 1. 앱 개요

### 앱 이름 및 포지셔닝
- **앱 이름**: Petory (Pet + Story의 합성어)
- **슬로건**: *"Pet Health Intelligence"*
- **핵심 포지셔닝**: 반려견의 일상을 타임라인으로 기록하고, 내장된 AI 분석 엔진이 건강 상태를 코칭해주는 **반려견 전용 디지털 건강 다이어리**
- **원조 프로젝트**: `dog-guardian` (반려견 수호자)라는 이름으로 시작된 프로젝트에서 리브랜딩 및 UI/UX 리디자인을 통해 탄생

### 앱의 4대 비전 (README 기준)
1. **디지털 트윈** – 한 마리 반려견의 평생 기록을 시간순으로 보관
2. **개인화** – 품종 / 나이 / 몸무게에 맞춘 맞춤 조언
3. **소통** – "오늘은 피곤해 보여요" 같은 자연어 기반 코칭
4. **안전** – 가족 관계, 위험 감지, 실종 방지

## 3. 디자인 시스템 (UI/UX)

### 컬러 팔레트 (Neo-Dark Warm Tone)
```
--bg:        #DCD7C9   (크림 베이지 — 배경)
--primary:   #2C3639   (다크 틸 — 주요 텍스트/헤더)
--secondary: #3F4E4F   (미디엄 틸)

```
이 팔레트는 로그인 화면과 앱 내부가 Dark(다크 틸) vs Light(크림 베이지)로 반전되는 구조로 설계됨

### 주요 UI 패턴
- **Glassmorphism 카드** (`.glass-card`): 배경 블러 + 반투명 백색 카드
- **고정 헤더**: sticky 상단 헤더(배경 블러 처리), 프로필 선택 드롭다운 포함
- **하단 네비게이션**: iOS 스타일 fixed bottom nav (80px 높이, safe-area 대응)
- **Screen Enter 애니메이션**: 탭 전환 시 `fadeSlideUp` 효과 (0.45s)
- **타임라인 뷰**: 수직 세로선 + 컬러 점(dot) + 슬라이드업 아이템
- **음악 바 비주얼라이저**: 화면 상단 중앙 고정, 5개 바(bar)가 춤추는 애니메이션

### 반응형 레이아웃
- `max-width: 430px`로 모바일 퍼스트 설계
- 모든 레이아웃이 스마트폰 세로 화면에 최적화

## 5. 기능 상세 분석

### 5-1. 로그인 화면 (LoginScreen)

**핵심 플로우**:
- 이메일 + 비밀번호 입력 → 로그인 시도 → 실패 시 자동으로 회원가입으로 전환 (UX 단순화)

- 로그인 전에도 프리미엄 팩 정보 조회 가능 (Pre-purchase UX)

**UI 특징**:
- 다크 카드(`#3F4E4F`) + 크림 텍스트 배색
- 배경에 `radial-gradient` 미세 텍스처
- 상단 좌우에 언어 전환(EN/KO) + 프리미엄 버튼 배치
- 포커스 시 입력 필드 테두리가 갈색 accent색으로 변환

### 5-2. 탭 1 — 프로필 화면 (ProfileScreen)

반려견의 기본 정보를 입력하고 관리하는 화면.

#### 기능 목록
| 기능 | 설명 |
|---|---|
| **사진 업로드** | 로컬 이미지 선택 → Canvas API로 최대 300px 리사이즈 + JPEG 0.7 압축 후 base64로 저장 |
| **기본 정보 입력** | 이름, 견종, 생년월일, 사진 URL |
| **나이 자동 계산** | 생년월일 기반으로 개월 수 계산 → `퍼피 / 성견 / 노령견` 단계 자동 분류 |
| **건강 요약 타일** | 성장단계 / 체중 / 접종일 / 다음 진료일을 2x2 그리드로 표시 (인라인 편집 지원) |
| **체중 단위 전환** | kg ↔ lbs 버튼 탭 한 번으로 자동 변환 + 즉시 서버 저장 |
| **프로필 저장** | `/api/profile` POST 요청, 저장 성공 시 "✓ 저장 완료" 피드백 2.5초 표시 |
| **프로필 삭제** | 확인 대화상자 후 `/api/profile` DELETE 요청 |

#### 성장 단계 분류 기준
```
0 ~ 11개월   → 퍼피 (Puppy)
12 ~ 83개월  → 성견 (Adult)
84개월 이상  → 노령견 (Senior)
```

- **무료 유저**: 황금색 "가디언 패밀리팩" 업셀 카드 ($4.99 → 상세보기 버튼)

### 5-4. 탭 3 — AI 인사이트 화면 (AiReportScreen + DogEngine)

앱의 핵심 차별화 기능. **DogEngine**이라 불리는 내장 분석 엔진이 타임라인 데이터를 분석하여 수의학적 조언을 제공.

#### DogEngine 분석 로직 (dogEngine.js)

**입력 데이터**:
- 최근 24시간의 타임라인 기록
- 반려견 프로필 (생년월일 → 나이 카테고리 도출)

**분석 단계**:
1. **나이 카테고리 결정**: 개월 수 계산 → 퍼피/성견/노령견 분류
2. **24시간 데이터 집계**: 각 활동 유형별 횟수 카운트
3. **메트릭 평가**:
   - **수면(Sleep)**: 0회=poor, 1회=good, 2회 이상=excellent
   - **활동(Walk)**: 0회=zero(경고), 1회=low, 2회=good, 3회 이상=high
   - **식사(Diet)**: 0회=emergency, 1회=low, 2회=good, 3회 이상=high
4. **코칭 카드 생성** (조건별 로직):
   - 퍼피 + 산책 3회 이상 → "퍼피 관절 주의보"
   - 퍼피 + 식사 3회 이상 → "퍼피 폭풍 성장기 식단" (긍정 피드백)
   - 노령견 + 산책 3회 이상 → "노령견 과활동 경고"
   - 산책 0회 + 식사 3회 이상 → "소화불량 및 비만 경고"
   - 산책 0회 → "활동량 0 경고"
   - 병원 방문 감지 → "병원 스트레스 케어" 조언
   - 식사 2회 + 산책 1회 이상 → "Perfect Day!" 칭찬
5. **다형성 텍스트**: 각 상태에 최소 3개의 랜덤 문구 풀 → 반복 접속 시 다양한 피드백 제공

**출력 구조**:
```
summary   : 오늘의 한 줄 요약 (반려견 이름 포함)
description : 분석 모드 + 수치 요약 + 상세 설명
metrics   : 수면 / 식사 / 활동 각각의 상태(status), 라벨, 색상
coaching  : 최대 3개의 코칭 카드 (제목 + 설명 + 색상)
```

**언어 지원**: KO / EN 완전 이중 언어 (모든 텍스트 풀이 두 언어로 별도 구성)

#### AI 인사이트 화면 UI
- **분석 로더**: 스피너 + "DogEngine이 데이터를 처리하고 있습니다..." (1초 딜레이로 몰입감 부여)
- **영웅 요약 카드**: 검은 배경 + 이탤릭 세리프 폰트 + 황금 그라디언트 오버레이
- **바이탈 지표**: 수면 / 식사 / 활동 3개 카드 (3열 그리드)
- **코칭 카드**: 좌측 색상 바(accent bar) + 제목 + 설명 텍스트

## 7. 프리미엄 구독 시스템 (가디언 패밀리팩)

### 결제 정보
- **가격**: $4.99 (원가 $9.99, 50% 할인 표기)
- **결제 방식**: Stripe Checkout (외부 페이지 리다이렉션)
- **결제 유형**: **1회성 영구 결제** (월 구독 아님)
- **결제 성공 처리**: URL 파라미터 `?premium=success` 감지 → 프리미엄 상태 즉시 활성화

### 프리미엄 혜택 (4가지)
1. **무제한 반려견 프로필** (무료: 2마리 제한)
2. **프리미엄 테라피 오디오** 전곡 해제 (무료: 1곡만 사용 가능)
3. **VIP 수의학 건강 리포트** 내보내기 기능
4. **추가 비용 없는 영구 소장권**

### 프리미엄 모달 진입점 (4곳)
1. 헤더의 "👑 프리미엄" 버튼
2. 프로필 화면의 업셀 카드
3. 오디오 플레이어에서 잠금 트랙 선택 시
4. 2마리 초과 반려견 추가 시도 시

## 8. 테라피 오디오 시스템 (AudioPlayerModal)

### 구조
- 총 **15개 트랙**, 5개 카테고리로 구분
- 1개는 무료(Free), 14개는 프리미엄(Premium)

### 오디오 카테고리 (5가지)
| 카테고리 (KO) | 카테고리 (EN) | 트랙 수 |
|---|---|---|
| 수면 유도 | Sleep Therapy | 3개 |
| 불안 완화 | Anxiety Relief | 3개 |
| 집중, 학습 | Focus & Training | 3개 |
| 힐링 회복 | Healing & Recovery | 3개 |
| 일상 루틴 | Daily Routine | 3개 |

### 플레이어 UX
- **화면 상단 고정 MusicBar**: 5개 막대 애니메이션이 재생/일시정지 상태를 시각화, 클릭 시 플레이어 모달 팝업
- **바텀시트 모달**: 위에서 슬라이드업 애니메이션 + 스와이프 다운으로 닫기 (터치 제스처)
- **빙글빙글 도는 LP 이미지**: 재생 중인 트랙이 LP처럼 회전
- **트랙 목록**: 카테고리 탭 필터링, 현재 재생 중인 트랙 강조 + 사운드바 애니메이션 표시
- **잠금 트랙**: 자물쇠 아이콘 표시, 클릭 시 프리미엄 모달로 연결
- **이전/다음 트랙**: 프리미엄 트랙 접근 시 프리미엄 모달로 자동 전환

### 앱 레벨 오디오 상태 관리
- `index.js`의 Root 컴포넌트가 오디오 상태 전역 관리
- `<audio>` 엘리먼트는 DOM에 숨겨져 백그라운드 재생
- 탭 전환 시에도 음악 끊김 없이 지속 재생

## 11. VIP 수의학 건강 리포트 (ReportSampleModal)

프리미엄 가입 유도를 위한 샘플 리포트. 실제 기능은 미구현이나 UI 샘플로 구현됨.

**리포트 구성 요소**:
- 반려견 이름 + 종합 웰니스 점수 (100점 만점, 예: 92점)
- 식단 및 소화 분석
- 수면 및 스트레스 회복 분석
- 활동 밀도 및 심혈관 분석
- 동일 품종 평균 대비 벤치마크 + 진행률 바
- 주의 및 경고 시그널 (3일 연속 수분 섭취 기록 미입력 등)
- "담당 수의사 제출용" 전자서명 문서 형태의 포지셔닝

## 13. 핵심 차별화 포인트 (경쟁 우위)

1. **DogEngine (로컬 AI 분석)**: 외부 API 없이 앱 자체에서 수의학적 조언 제공 → 비용 없음, 오프라인 작동 가능성
2. **나이 맞춤 코칭**: 퍼피/성견/노령견을 구분하여 완전히 다른 조언 제공
3. **1회성 결제 모델**: 월구독 피로감 없음, 사용자 친화적
4. **테라피 오디오 통합**: 반려견 건강 앱과 힐링 사운드의 결합 (차별화된 콘텐츠)
5. **VIP 수의학 리포트**: 실제 동물병원 제출용 문서 형태의 포지셔닝 (고급화 전략)
6. **한/영 완전 이중언어**: 글로벌 시장 대응 가능
